# ThirteenAsh 个人空间

Vue 3 + TypeScript 前端、Go 后端。

## 已实现功能

| 模块 | 行为 |
| --- | --- |
| 首页 | 可编辑个人介绍、按展示顺序单列展示最多四件已发布的精选作品、文章和日常混合按首次发布时间倒序展示最新五条记录、长文正文最多三行并在第三行渐隐、关于我 |
| 作品 | 独立的后台作品管理及编辑入口、全部/首页精选筛选、Markdown 介绍、技术栈、顺序、仓库信息卡及链接编辑和即时预览 |
| 文章 | 独立的文章列表和后台管理，保留现有长文章、随笔的页面及 Markdown 编辑器 |
| 日常 | 独立的简约时间流及编辑页，无标题、内容标记、封面和摘要；Markdown 配文在上、0–9 张配图在下；支持批量上传、拖动和按钮排序；可发纯文字或纯图片，按首次发布时间倒序 |
| 编辑器 | 文章原文/Markdown 预览通过“编写 / 预览”页签切换、作品 Markdown 并排预览、常用格式按钮、插图、封面、配图、摘要提取、Ctrl/⌘+S、离开时提醒未保存修改 |
| 发布 | 草稿、发布、修改、撤回、删除；草稿不出现在公开详情、列表、搜索和互动接口中 |
| 搜索 | 搜索已发布作品、文章、动态的标题、摘要、正文、仓库名称及描述；支持中文和分页 |
| GitHub | 读取配置用户的公开仓库、勾选导入草稿、防重复导入、手动同步、每日同步 |
| 图片库 | 真实图片检查、上传、选择、预览、复制地址、删除；已有内容或站点信息引用的图片拒绝删除 |
| 互动 | 匿名浏览器 Cookie 点赞一次/取消；浏览 30 分钟去重；短动态卡片进入视野也计浏览 |
| 后台 | 账号密码登录、工作台统计、作品管理、文章管理、日常管理、GitHub 导入与同步、图片库、站点设置、修改密码、退出登录 |
| 公开页面 | 电脑和手机适配、主题切换、独立链接、图片放大、404 和错误重试 |

内容标记与仓库主要语言支持每行一项，自动忽略空行与重复项，前台分别展示为彩色标签。内容标记最多 20 项、每项 40 字；主要语言最多 20 项、每项 100 字。
